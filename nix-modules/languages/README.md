# Language modules

- `dotnet/dotnetdevpkgs.nix`: .NET SDK 10.
- `lisp/common-lisp.nix`: SBCL, Coalton, rlwrap, and ASDF.
- `lisp/scheme.nix`: Chez Scheme, Guile, and Chicken.
- `nix/nix.nix`: `nixd` and `nixfmt`.
- `nodejs/fnm.nix`: `fnm` and pnpm; its shell hook runs `fnm install` and `fnm use`.
- `nodejs/pnpm.nix`: Node.js, Corepack, and pnpm.
- `nodejs/yarn.nix`: Node.js, Corepack, and Yarn.
- `python/python314.nix`: Python 3.14, `pydevd`, `uv`, and Pyright.
