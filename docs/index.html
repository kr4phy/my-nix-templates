About

This is a collection of Nix flake templates and modules for setting up development environments. You can use Python scripts to create, list, and validate templates or modules.

Requirements

  • Nix (tested with Nix 2.35.3)
  • Git
  • Python 3.x (for scripts)

Platform Support

  • Linux (x86_64): Supported
  • macOS (aarch64): Not tested, but likely supported
  • Windows (WSL2): Supported
  • Windows (Native): Not supported (due to lack of Nix support)
