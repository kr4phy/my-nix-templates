# Shell Scripting Environment

This template provides a shell scripting environment with multiple shell options.

## Features

- Oh-My-Zsh with syntax highlighting and auto-suggestions
- Oh-My-Posh for PowerShell
- Oh-My-Bash

## Commands

- `omz`: Run zsh shell with oh-my-zsh
- `omp`: Run PowerShell with oh-my-posh
- `omb`: Run bash shell with oh-my-bash
- `zsh`: Run vanilla zsh
- `pwsh`: Run vanilla PowerShell
- `bash`: Run vanilla bash
